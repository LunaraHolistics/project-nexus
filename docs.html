02 — Novidades da v2.0

Evoluções Técnicas Principais

Integração Backend Real

  • Comunicação resiliente com Node.js (fallback para MOCK se offline).
  • Persistência de estado via localStorage e banco SQLite.
  • Sistema de upgrades e progressão de jogador funcional.

Imagens Dinâmicas (IA)

  • Geração procedural de imagens via Pollinations AI.
  • Cada missão e artefato possui uma imagem única baseada em seu nome e categoria.
  • Seed fixo por ID para consistência visual entre recarregamentos.

Feedback Imersivo

  • Sistema de notificações Toast nativo (ArchiveAPI.notify).
  • Integração completa com audio-system.js para cliques, sucessos e erros.
  • Animações de entrada e transições refinadas em todas as telas.

Localização Funcional

  • Sistema de tradução i18n nativo na tela de configurações.
  • Suporte a PT-BR, EN-US, FR-FR e DE-DE com persistência de preferência.
  • Dicionário expansível para futuras adições de idioma.

04 — Instalação

Como Instalar e Rodar

Instalar Node.js

Baixe e instale Node.js 18+ de nodejs.org

Instalar Dependências do Backend

cd backend npm install

Configurar Variáveis de Ambiente

# Edite backend/.env: PORT=3000 FRONTEND_URL=http://localhost:5500 NODE_ENV=development

Iniciar Backend

cd backend npm run dev # Servidor rodará em http://localhost:3000

Servir Frontend

# Opção 1: VS Code Live Server (Recomendado) # Clique direito em index.html → "Open with Live Server" # Opção 2: Python python3 -m http.server 5500 # Opção 3: Node.js npx http-server -p 5500
05 — API Reference

Endpoints Principais

Missões

  • GET /api/missions — Lista missões (Retorna { "missions": [...] })
  • POST /api/missions/generate — Gera missão procedural
  • POST /api/missions/:id/accept — Aceita missão (requer player_id)
  • POST /api/missions/:id/complete — Completa missão e distribui recompensas

Jogador

  • POST /api/player — Cria novo jogador
  • GET /api/player/:id — Retorna perfil, missões ativas e upgrades
  • PUT /api/player/:id — Atualiza dados do jogador (XP, créditos, etc)
  • POST /api/player/:id/upgrades — Compra um upgrade (valida créditos)

Archive (Acervo)

  • GET /api/archive/artifacts — Lista artefatos (Retorna { "artifacts": [...] })
  • GET /api/archive/suspects — Lista suspeitos
  • GET /api/archive/upgrades — Lista árvore de upgrades disponíveis
  • GET /api/archive/stats — Retorna estatísticas globais do acervo

Sistema

  • GET /api/health — Health check do servidor
  • CORS habilitado para localhost:5500 e 127.0.0.1:5500
  • Rate limiting: 100 req/15min por IP
  • SQLite com persistência em nexus.db
