03 — Instalação

Como Instalar e Rodar

Instalar Node.js

Baixe e instale Node.js 18+ de nodejs.org

Instalar Dependências do Backend

cd backend npm install

Configurar Variáveis de Ambiente

# Edite backend/.env: PORT=3000 FRONTEND_URL=http://localhost:5500 NODE_ENV=development

Iniciar Backend

cd backend npm run dev # Servidor rodará em http://localhost:3000

Servir Frontend

# Opção 1: VS Code Live Server # Clique direito em index.html → "Open with Live Server" # Opção 2: Python python3 -m http.server 5500 # Opção 3: Node.js npx http-server -p 5500
04 — API Reference

Endpoints Principais

Missões

  • GET /api/missions — Listar missões
  • GET /api/missions/:id — Detalhes da missão
  • POST /api/missions/generate — Gerar missões procedurais
  • POST /api/missions/:id/accept — Aceitar missão
  • POST /api/missions/:id/complete — Completar missão

Jogador

  • POST /api/player — Criar jogador
  • GET /api/player/:id — Perfil do jogador
  • PUT /api/player/:id — Atualizar jogador
  • POST /api/player/:id/upgrades — Comprar upgrade

Archive

  • GET /api/archive/artifacts — Listar artefatos
  • GET /api/archive/suspects — Listar suspeitos
  • GET /api/archive/stats — Estatísticas

Sistema

  • GET /api/health — Health check
  • CORS habilitado para localhost:5500
  • Rate limiting: 100 req/15min
  • SQLite com WAL mode
